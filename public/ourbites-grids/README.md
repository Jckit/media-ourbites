# Ourbites grid overlays

Six portrait **1080 × 1920 RGBA PNG** overlays for Remotion: `red`, `teal`, `electric-blue`, `violet`, `amber`, and `ice-white`.

Use `<EditorialGrid tone="electric-blue" travel={0.35}/>` or any other tone. The existing `travel` and `dark` behavior is unchanged; choose a tone to suit the scene rather than forcing one channel-wide background.

Original grid artwork and six color references were supplied by the user (2026-11-03). Existing teal/amber/violet PNGs are preserved unchanged. The new red/blue/white PNGs are palette-matched recreations from the same user-supplied grid and preserve the original alpha/grid geometry; they are not byte-for-byte copies of the uploaded color files. No third-party license is inferred; publication/rights checks remain separate.
