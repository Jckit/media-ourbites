# Ourbites: framework-level direction

Justin clarified in this chat on 2026-10-28: this task improves the high-level framework so it is repeatable and reusable for future episodes, not only Anthropic.

## Delivery objective

Build on the existing production pipeline and shared Remotion components. Anthropic is a regression/example fixture. Prioritize reusable capabilities with clear configuration, stable visual identity and practical production steps. Avoid one-off scene polish masquerading as framework progress.

## Acceptance for each framework batch

- Identify a concrete recurring limitation and implement one bounded shared improvement.
- Separate episode facts, names, script and timing inputs from reusable animation/layout mechanics.
- Demonstrate use in Anthropic plus a meaningfully different existing episode/scenario or explicitly synthetic fixture. Vary the relevant content, layout or timing; a renamed duplicate is insufficient.
- Render and inspect affected moments, run relevant checks, document the interface/example and constraints. Distinguish still inspection from actual playback/listening.
- Record what future episode work becomes easier and any remaining manual steps. Do not claim a fully automated pipeline from a component or document alone.

## Candidate priorities (select by evidence)

1. Shared scene layout anchors, foreground/background planes and caption/identity-label safe zones.
2. Configurable environments and visual tokens for the hybrid style with restrained optional low-poly depth.
3. Reusable actor gaze, reach, grip and prop actions with explicit timing and coordinates.
4. Episode content/configuration boundaries and actual-audio-driven captions/scene timing.
5. Reusable storyboard inputs and practical research, factual verification, asset, render and human-review handoffs.

Reuse existing modules first; avoid speculative engines, infrastructure and rigid story templates. The style reference does not require simulations or multiple locations. Preserve the expressive cream/navy/teal characters, Voice A, 1.1x playback, factual accuracy and human release gates.

The existing subjective character-design cap does not block non-aesthetic framework engineering. This clarification is not unlimited art redesign permission or approval of final media.
