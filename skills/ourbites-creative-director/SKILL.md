## Creative reasoning sequence

1. **Find the visual thesis.** One sentence: 'The audience starts believing/seeing X, then understands Y because Z changes.' Define a visual question, one causal mechanism, and payoff. Select a focal object that can persist across beats when useful. Do not force continuity if it obscures the explanation.
2. **Break the script into meaningful beats.** For every spoken phrase, specify the viewer's prior knowledge, new information, on-screen evidence and changed state. One beat is not automatically one slide or cut. Explicitly mark fact, analysis and hypothetical.
3. **Cast and block.** Reuse canonical Ourbites host, with motivated glance, gesture, reach, grip, release, reaction and screen position. Give supporting real figures sourced identity/likeness constraints; do not invent what they physically did. For any new fictional character, define silhouette, palette, proportions, face/pose set, layers, rig interface and consistency tests before generating or coding assets. Distinguish **character description** from **character action**.
4. **Art-direct an editorial film.** Default to the reference-led editorial hierarchy (typographic evidence, original annotated graphics, layered interfaces and purposeful negative space); use scenic hybrid 2D/2.5D, paper collage or exact-data explanation only when the mechanism needs it. Art-direct original compositions: depth planes, crop, typography hierarchy, negative space, mobile-safe zones, shadows, materials, evidence labels and camera grammar. Use the reference video as a *quality benchmark*, not a template to trace. Paper collage is optional.
5. **Design three intentional style frames** (opening, mechanism, payoff) for any new visual direction. Record precise dominant subject, visual hierarchy and source/destination anchors. If actual frames cannot be produced, label these as written keyframe specifications; do not pretend they are renders.
6. **Make the build list.** Each shot has actor/object, action verb, start/end pose, spatial anchors and coordinate owner, **spatial Bézier handles, temporal Bézier timing, intended velocity through joins and individual offsets for typography/background/host**, overlap/occlusion, cues relative to narration, hold/readability, transition cause, safe areas and fallback. Do not use one default easing for all graphics. Distinguish graphic primitives from motion behaviors and from episode-specific content. No teleporting, unrelated wipes, arbitrary springs or one-click 'make it dynamic'.
7. **Select motion assets.** Only `catalog.accepted` is approved for production reuse. Candidates may be proposed for *isolated review* but never silently promoted. If no accepted recipe fits, create one original candidate brief and ask for rendered review. Reuse existing host and scene-kit code.
8. **Direct voice and sound.** Script approval precedes narration lock. Preserve the existing Voice A `am_puck`, original pitch and 1.1x playback where applicable. Use measured word timestamps for action cues and captions. Create an SFX cue sheet with exact visual event, material, in/out, loudness intention and rights status; no automatic SFX on every movement. Music is optional and subordinate to narration.
9. **Hand off to Codex.** Produce the complete package specified in the handoff contract below: one creative brief, cast sheet, scene cards, animation tickets, narration/SFX/caption cue sheet, asset/rights register, QA/acceptance plan and a build order. Prefer code-ready measurable instructions, not vague adjectives.
10. **Review real outputs.** Codex renders at 432×768; director and viewer inspect normal-speed playback, beginning/middle/payoff, adjacent frames around handoffs, actual visible acceleration/deceleration, background/hero/type pace differences, sound and caption alignment. Specifically reject presentation-style full-rectangle enlargement, mechanical smoothstep pauses at intermediate keyframes and static repeating scene compositions. Rate visual coherence and legibility with evidence. Code or stills alone do not prove motion quality. Return timestamped fixes to implementer. Keep subjective human art gate, Gate B and final Gate C separate.

## Non-negotiable creative bar

- Every motion answers: **what changed in the business explanation?** A purposeful hold is better than decorative animation.
- Design the entire **editorial composition**, not floating labels or a permanent illustrated room. Establish focal hierarchy, foreground/midground/background and believable contact where props are physical.
- Use object continuity when it aids comprehension: a single logical object moves from source to destination; hands/gaze/occlusion track the same anchors.
- Keep the host recognizable; do not re-design the protagonist or use unapproved likenesses. Human character approval is not inferred from a functioning SVG.
- Maintain factual labels, source qualifications and 'illustrative' tags through transitions; finance math must not morph into a different claim.
- Source and licensing for authentic footage, music, sound, fonts and art are independent gates. No copying or redistributing user reference footage.
- Separate **direction-approved**, **implemented**, **render-verified**, **human-art-accepted** and **published**. Never infer one from another.

## Caption direction and controlled variability — human update 2026-11-01

- **Word-by-word is the default** for narrated new production: each spoken word must have an **actual measured source-audio start and end time**; reveal its own word with a brief, contained opacity fade on utterance. Keep prior words readable within the chosen line. Phrase-level pause cues are insufficient; never distribute words evenly across a phrase or claim synchronization from synthetic demo timings.
- Build semantic metadata per token, **not random typography**: `normal`, `person` (distinct italic/underlined treatment), `company` (approved licensed local logo if available; otherwise clear styled wordmark), `emphasis` (restrained color/weight). The director nominates words, the sound-alignment/rights passes validate times and assets. A logo is **not** cleared merely because it is publicly visible. Avoid misleading imitation of brand artwork.
- Preserve a recognizable subtitle baseline: placement, safe areas, type scale, contrast, fade duration and line grouping. Semantic emphasis should be rare and meaningful; captions must not compete with the explanatory graphic or obscure source caveats.
- Use deterministic episode/scene/object-seeded variation for background specks, collaged material irregularity and a few secondary offsets only. Don't randomize exact business visuals, captions/word timing, proper names, source status, character proportions, main motion causality or final media reproducibility. The hero path still receives deliberate authored Bézier controls and varied timing.
- Write cues into `audio-cues.md` and the word-caption data contract `src/framework/captions/word-captions.ts`. Pass source-clock seconds; playback at 1.1× requires `frame / fps * playbackSpeed`. Existing phrase-timed prototypes remain unchanged until word alignment is actually performed.
